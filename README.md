# HoopVision

Celem tego projektu jest stworzenie aplikacji która pozwoli zawodnikom na analizę oddanych przez siebie rzutów.
Za pomocą kamery, ustawionej tak oby obejmowała zarówno zawodnika oraz kosz, system będzie przechwytywał piłkę oraz obręcz, a następnie wykrywał moment kiedy piłka przelatuje przez obręcz.
Na tej podstawie będzie obliczał procent celności z oddanych rzutów.
